# Interview video files

Recordings are intentionally local and are not included in the starter. Add MP4 files with these exact names:

- `welcome.mp4`
- `manual-workflow.mp4`
- `complex-integrations.mp4`
- `modernize-frontend.mp4`
- `evaluate-ai.mp4`
- `evolving-ai-product.mp4`
- `frontend-architecture.mp4`

List-page videos play muted and loop only while at least 55% of the thumbnail is visible. The expanded response uses normal video controls. Keep transcripts in `src/lib/interview-responses.ts` synchronized with every final recording.
